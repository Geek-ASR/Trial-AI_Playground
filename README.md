# NeuralCraft

NeuralCraft is a free, browser-based 3D playground for learning AI, machine learning, and data science through interactive experiments.

Instead of only reading about algorithms, you can walk around a small voxel world, visit different labs, write real code, and see the results visually.

## What you can explore

The project currently includes 36 lessons covering:

- Math and statistics
- Linear and logistic regression
- k-NN and k-means
- Neural networks and backpropagation
- Embeddings and attention
- Q-learning and reinforcement learning

There are also six interactive labs:

- Gradient Descent
- Galton Board
- K-Means
- Neural Network / MNIST
- Embeddings
- Q-Learning



A separate sandbox lets you build structures using Blockly, Python, or JavaScript.
You can create voxel structures as well as shapes such as spheres, cylinders, cones, domes and rings.
The world itself includes multiple biomes, lighting, shadows, weather, water, a day/night cycle, ambient sound, flocking birds and an A* pathfinding guide.

Complete lessons, quizzes and coding exercises to earn credits, XP, levels and badges.
Progress is stored locally in the browser. No account is required.

## Tech

TypeScript, Vite, Three.js, Blockly, CodeMirror 6, Pyodide, Web Audio API and Vitest.

No backend, database, tracking or authentication.

## Running locally

bash npm install npm run dev 

Other commands:

bash npm run build npm test npm run news npm run smoke 

## Why I built it

I wanted to experiment with a different way of teaching AI — making concepts something you can interact with rather than just read about.
NeuralCraft started as a 3D simulation experiment and gradually grew into a larger interactive learning environment.
